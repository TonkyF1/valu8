# Frontend SEO architecture

- Keep public route metadata in the Node-safe `src/data/routeMeta.ts`; pages, build HTML and sitemaps consume it to prevent drift.
- Generate route head variants with a dependency-free build-only Vite plugin; preserve the SPA body and fail when required template tags are missing.
- Per-route prerendered HTML is chosen in scripts/routePages.ts (used by vite.config.ts and tests) so tests check exactly what the build emits; /value/<slug> is the only indexable model page and matched /car-values model pages are redirect stubs, so internal model links go through carHref.
- src/data/valueSlugRegistry.ts is add-only: every published /value slug keeps an indexable page (no-price fallback, never in the sitemap), and build-time route data from it fills the index.html unknown-route script so only real model/year/car-values paths count as known.
- Model names shown on /value, year, hub and /car-values redirect pages (incl. JSON-LD) come only from modelDisplayName (src/data/modelDisplayName.ts, slug-keyed overrides); slugs/URLs never use it.
- /value model pages carry the full year table, depreciation (5–35% only), mileage table and price-type explainer from MODEL_PRICES, with WebPage JSON-LD dateModified = VALUE_PAGES_MODIFIED_ISO (bump it with each price-data refresh). Internal links to the most-searched models come only from src/data/popularModels.ts (homepage, guides). The sitemap (scripts/sitemap.ts) lists exactly the canonical, indexable pages (inSitemap); its URL set must not change unless Tony approves. Each URL has a real <lastmod>: /value pages use VALUE_PAGES_MODIFIED_ISO, every other page its date in src/data/pageLastmod.ts. Bump that date when you change a page's visible copy (not for styling or app-flow changes), then run `bun scripts/sitemap.ts`.
- Advert-check outcome logging lives in fair-price/advert-followup/recheck-adverts; logging must be best-effort so a logging failure never changes or breaks a price result. Link denylist + robots rules live in _shared/adverts.ts and _shared/robots.ts (single source for both).
- App emails go through Resend from supabase/functions/email-dispatch (DB trigger for report emails, daily cron for follow-ups) with _shared/email.ts; every email must carry the signed unsubscribe link and respect email_suppressions, so one opt-out stops all mail.
- Homepage car imagery uses modelRenders model/year matching with body-shape fallbacks and displays source images directly, avoiding canvas repaint overhead.
- The homepage price-arc grade is computed client-side in src/lib/carGrade.ts from real report signals only (mileage for age, latest DVSA MOT, photo score, MOT mileage drop); unchecked items like finance/write-off must never feed it.
- Hand-written copy for single /value/<slug> model pages lives in src/data/enrichedModels.ts (figures only from MODEL_PRICES, rendered in build HTML and React, FAQs merged into valueGuidance); its modifiedIso sets that page's lastmod and dateModified via valuePageModifiedIso, so one page's edit never redates the rest. Enriched pages may also carry a rival price table (rivalsMarkdown: band medians from MODEL_PRICES, links only to /value pages) and guide links; title/description are optional overrides, otherwise valueTitle (always "How much is my X worth?") applies.
- Copy shared by every /value/<slug> page (valueIntro, H2s such as "X value by year" and "Selling your X", valueMeta descriptions) is dated by VALUE_COPY_MODIFIED_ISO in valuePages.ts: bump it when you change that shared copy. valuePageModifiedIso takes the latest of VALUE_PAGES_MODIFIED_ISO (prices), VALUE_COPY_MODIFIED_ISO and the enriched modifiedIso. Electric models in EV_VALUE_SLUGS link to /guides/electric-car-value.
- marketConfidence is a guarded AI call (conf-ai-1, _shared/aiConfidence.ts): the rule level is kept as report.confidenceData, the AI may move it one step (never High on lessCertain sanity, <10 relevant comps, imports or 20+ year cars) and only the four confidence keys are ever set. Switch with the AI_CONFIDENCE secret (off | shadow | on, default on); AI_CONFIDENCE_MODEL defaults to google/gemini-2.5-flash-lite.
